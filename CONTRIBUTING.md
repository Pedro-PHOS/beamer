# Desenvolvimento deste fork

Este é um fork pessoal para Windows e Linux do Beamer de Kalkman Code, sob GPL-3.0.
Mudanças locais não representam releases oficiais do upstream.

Use `README.md` para executar e empacotar. Preserve `LICENSE` e avisos de autoria.
Registre mudanças em `docs/FORK.md` e mantenha os testes dos backends suportados.
Os testes da interface Qt requerem PySide6; testes nativos Windows requerem Windows.
Para conferir as traduções: `python tools/i18n_extract.py --check --complete`.
Logs podem conter nomes e endereços de máquinas; revise antes de compartilhar.
